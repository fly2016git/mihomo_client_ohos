4. 服务内容

ClashGuard 主要提供以下功能：

  1. 创建、导入、编辑、删除和切换代理配置；
  2. 添加及更新用户提供的 HTTP/HTTPS 订阅地址；
  3. 调用系统 VPN 能力，根据用户配置处理和转发网络流量；
  4. 查看及切换配置中包含的代理节点；
  5. 选择路由模式、DNS 模式及其他运行设置；
  6. 查看连接状态、实时流量、运行日志和诊断信息；
  7. 通过系统文件选择器导入配置文件；
  8. 通过系统扫码能力识别订阅地址；
  9. 提供应用运行所需的本地 GeoIP 数据。

我们不提供、销售或推荐任何代理节点、订阅服务或网络内容，也不保证用户自行添加的配置、节点或订阅服务真实、合法、安全、稳定或持续可用。

我们可能根据应用维护、安全或法律要求调整部分功能，并通过应用更新、发布页面或源代码仓库进行说明。
